راهنمای ادامه پروژه ELEMENT X فقط با گوشی اندرویدی
=================================================

این بسته سورس پروژه است، نه فایل نصب نهایی. APK آزمایشی و فایل قابل انتشار در فروشگاه یکی نیستند.

ساخت APK آزمایشی از طریق GitHub Actions با گوشی:
1) در مرورگر گوشی وارد GitHub شوید یا حساب بسازید.
2) یک مخزن جدید بسازید و فایل‌های داخل این پوشه را بارگذاری کنید (محتویات پوشه، نه خود پوشه والد).
3) پس از بارگذاری در شاخه main، بخش Actions را باز کنید و workflow با نام Build Android test APK را اجرا کنید.
4) پس از موفقیت، در اجرای workflow بخش Artifacts فایل ELEMENT-X-debug-APK را دانلود کنید.
5) این APK فقط برای آزمایش روی گوشی است و برای انتشار عمومی در فروشگاه آماده نیست.

برای نسخه قابل انتشار:
- باید کلید امضای انتشار (release keystore) ایجاد و امن نگهداری شود؛ آن را در چت یا مخزن عمومی قرار ندهید.
- نسخه Release باید با همان کلید امضا و روی چند دستگاه آزمایش شود.
- اطلاعات ناشر، سیاست حریم خصوصی نهایی، آیکون و اسکرین‌شات‌های واقعی، رده‌بندی سنی و فرم‌های محتوایی فروشگاه تکمیل شوند.
- الزامات فنی و قالب خروجی را در پنل فعلی بازار بررسی کنید؛ ممکن است APK امضاشده یا قالب دیگری درخواست شود.

قبل از انتشار عمومی، صحت علمی داده‌های عناصر و ترجمه‌ها بازبینی شود. سیاست حریم خصوصی این بسته پیش‌نویس است؛ اطلاعات تماس ناشر باید اضافه شود. این پروژه فعلاً حساب کاربری، پرداخت یا تبلیغات ندارد و پیشرفت را محلی ذخیره می‌کند.
