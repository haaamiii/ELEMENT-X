ELEMENT X — نسخه 0.2 | وب‌اپ + آماده‌سازی اندروید
====================================================

وضعیت فعلی
- جدول تعاملی شامل ۱۱۸ عنصر
- جست‌وجو بر اساس نام فارسی/انگلیسی، نماد و عدد اتمی
- فیلتر دسته‌های اصلی عناصر
- صفحه اطلاعات هر عنصر
- بخش آموزشی ساختار اتم
- آزمون پنج‌سؤالی با امتیاز XP
- رابط فارسی/انگلیسی؛ گزینه‌های آزمون هم با زبان هماهنگ می‌شوند
- ذخیره امتیاز و عناصر مشاهده‌شده روی همان دستگاه
- PWA با پشتیبانی اولیه آفلاین
- ساختار آماده برای بسته‌بندی با Capacitor در اندروید

فایل‌ها
- index.html / styles.css / app.js: نسخه وب اصلی
- www/: فایل‌هایی که داخل اپ اندروید بسته‌بندی می‌شوند
- package.json و capacitor.config.json: تنظیمات اولیه Capacitor
- manifest.webmanifest و sw.js: نصب وب‌اپ و کش آفلاین

اجرای سریع وب
1) Node.js نسخه LTS را نصب کن.
2) در ترمینال داخل پوشه پروژه اجرا کن: npm install
3) سپس اجرا کن: npm start
4) در مرورگر آدرس http://localhost:8080 را باز کن.

ساخت پروژه اندروید (نیازمند اینترنت و Android Studio)
1) داخل پوشه پروژه: npm install
2) بار اول: npm run android:add
3) برای انتقال تغییرات وب به اندروید: npm run android:sync
4) باز کردن پروژه در Android Studio: npm run android:open
5) در Android Studio، ابتدا روی دستگاه یا شبیه‌ساز تست کن؛ سپس از منوی Build گزینه ساخت APK یا Android App Bundle (AAB) را انتخاب کن.

نکته مهم: این بسته هنوز APK/AAB امضاشده نیست و به‌تنهایی در کافه‌بازار، مایکت یا Google Play منتشر نشده است. ساخت خروجی اندروید به نصب وابستگی‌ها، Android Studio، SDK و امضای نسخه انتشار نیاز دارد.

قبل از انتشار عمومی
